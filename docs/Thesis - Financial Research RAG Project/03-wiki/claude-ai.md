Anthropic's consumer app surface, and one of the four places [[agent-skills|Agent Skills]] run (see [[skills-across-surfaces]]). It supports both pre-built Agent Skills and custom Skills; custom Skills are uploaded as zip files via Settings > Features, are individual to each user, and cannot be centrally managed by admins ([[src-agent-skills-overview]]). Network access varies, and custom Skills do not sync to other surfaces ([[src-agent-skills-overview]]).
